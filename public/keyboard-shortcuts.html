Start / stop act the moment the key goes down, and the clock stops at the time of the press. Holding a key does not repeat it.
เริ่ม / หยุด ทำงานทันทีที่กดคีย์ลง นาฬิกาหยุดที่เวลาตอนกดจริง กดค้างไว้ไม่สลับซ้ำ
Change any key: Options → Keys. The keys in use are always listed in Control → ⌨ Help.
เปลี่ยนคีย์ได้: Options → Keys · คีย์ที่ใช้อยู่จริงดูได้ที่ คอนโทรล → ⌨ Help
Keys don’t work while typing in a box or while a window (sheet) is open on the control page.
คีย์ไม่ทำงาน ตอนพิมพ์ในช่องข้อความ หรือตอนมีหน้าต่างเปิดค้างบนหน้าคอนโทรล
Rink A / B controllers (small ice): only score and shot keys. Desktop app: F4 switches control ↔ scoreboard, F11 full screen on the scoreboard.
คอนโทรล Rink A / B (small ice): ใช้ได้แค่คีย์สกอร์และยิงเข้ากรอบ · แอป desktop: F4 สลับหน้าคอนโทรล ↔ สกอร์บอร์ด, F11 เต็มจอบนสกอร์บอร์ด
